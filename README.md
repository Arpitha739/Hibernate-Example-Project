**Merchant Product Management System**

Overview
Merchant Product Management System is a Java console-based application developed using Hibernate and JPA. The application allows merchants to manage their information and products through CRUD operations and authentication features.

**Features**

Merchant Operations
Save Merchant
Update Merchant
Find Merchant by ID
Verify Merchant using Email and Password
Verify Merchant using Phone Number and Password

Product Operations
Add Product
Update Product
Find Products by Merchant ID
Find Products by Brand
Find Products by Category

**Technologies Used**
Java
Hibernate ORM
JPA (Java Persistence API)
MySQL Database
Maven
Eclipse IDE
